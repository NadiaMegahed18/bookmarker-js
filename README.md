# 📚 Bookmarker System

A simple web application that allows users to save and manage their favorite website bookmarks. This project was built to practice **CRUD** operations (Create, Read, Update, Delete) and local storage.

## ✨ Features
* **Add Bookmarks:** Save a website name and its URL.
* **Validation:** Ensuring the site name and URL format are correct before saving.
* **Visit Website:** A quick link to open the saved bookmark in a new tab.
* **Delete:** Remove unwanted bookmarks from the list.
* **Persistent Data:** Uses `localStorage` to keep your bookmarks even after refreshing the page.

## 🚀 Technologies Used
* **HTML5**
* **CSS3** (Bootstrap/Custom CSS)
* **JavaScript** (DOM Manipulation & LocalStorage)
